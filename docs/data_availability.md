# Data availability

This public repository intentionally contains no participant-level behavioral data, identifying metadata, participant-level predictive-score vectors, fold manifests containing participant IDs, or participant-specific posterior objects.

The distributed aggregate frozen result tables are sufficient to regenerate the final reporting source data, all manuscript figures, and the computational summary values included in the public reporting layer.

Full computational refitting requires controlled trial-level behavioral inputs and fold-specific actor–control RL posterior artifacts obtained under the applicable ethics and data-access conditions. The public repository documents the required input structure in `docs/controlled_input_schema.md` without redistributing restricted data.

The MIT License applies to repository-authored software and documentation; it does not grant access to controlled participant-level data or supersede third-party data-use conditions.
