# Historical model-development source

These portable historical source snapshots document the computational branches that led to the canonical behavioral-computational study analysis. They are included so that candidate screening, control-model development, superseded implementations, and stopping decisions are not omitted from the public project history.

They are **not all current entry points**. Use `docs/analysis_lineage_and_decision_log.md` and `docs/analysis_stage_registry.tsv` to determine the status of each branch. Canonical downstream analyses live under `code/01_primary_action/` and `code/02_primary_joint_response/`; completed robustness analyses live under `code/03_robustness/`.

The invalid early behavioral-history implementation is represented in the lineage/registry but its source bytes were not present in the recovered source collection. It is therefore not reconstructed or invented here. The corrected implementation is included.

Original development-source SHA-256 identifiers are retained in `docs/model_development_source_hashes.tsv`.
