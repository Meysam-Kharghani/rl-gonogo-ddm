# Final manuscript reporting layer

This directory contains the publication-facing reporting assets for the final behavioral-computational manuscript.

- `figure_data/`: exact aggregate source data for Figures 1–4 and Supplementary Figures S1–S5.
- `table_data/`: publication-facing manuscript/Supplement table source data plus a numeric main-table representation; machine labels are normalized to the public naming policy without changing numerical content.
- `figures/`: frozen PNG/PDF/SVG assets regenerated by `code/04_reporting/make_publication_figures.py`.
- `source_data_map.tsv`: crosswalk from manuscript items to public source data and underlying frozen evidence.

The reporting layer contains no participant-level data. Run `make figures` to reproduce the frozen figure assets and verify exact SHA-256 identity.
